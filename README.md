# 🐍 100 Days of Code - Python Bootcamp (Angela Yu)

Bem-vindo(a) ao meu repositório do **100 Days of Code: The Complete Python Pro Bootcamp** ministrado por [Angela Yu](https://www.udemy.com/course/100-days-of-code/).  
Aqui estão todos os projetos, exercícios e desafios que desenvolvi ao longo dos 100 dias.

---

## 🎯 Objetivo
O curso é estruturado em 100 dias de prática com **Python**, cobrindo desde conceitos básicos até projetos avançados, com foco em desenvolvimento **back-end, automação, ciência de dados e web**.  
Este repositório serve para documentar minha evolução e organizar todos os códigos criados durante a jornada.

---

## 🛠️ Tecnologias e Bibliotecas Estudadas
Durante o bootcamp, trabalhamos com:

- **Python Básico e Intermediário**
  - Variáveis, funções, loops, condicionais
  - Listas, dicionários, tuplas, conjuntos
  - Programação Orientada a Objetos (POO)
  - Manipulação de arquivos

- **Módulos e Bibliotecas**
  - `random`, `datetime`, `os`, `smtplib`
  - `requests`, `beautifulsoup4`
  - `pandas`, `matplotlib`, `numpy`
  - `tkinter`

- **Projetos Web**
  - Flask
  - APIs REST
  - Automação com Selenium
  - Web scraping

- **Banco de Dados**
  - SQLite
  - SQLAlchemy

- **Outros**
  - Git & GitHub
  - Deploy com Heroku
  - Automação e Data Science
